# Predict-Bike-Sharing-Demand-with-AutoGluon-AWS
The goal of this project is to develop a machine learning model that accurately predicts bike rental demand. Using AutoGluon, an open-source AutoML library, the project aims to create baseline models without the need for extensive manual efforts like feature engineering, hyperparameter tuning, or model selection. By leveraging AutoGluon’s "Tabular Prediction" capabilities, the project seeks to streamline the model-building process and enhance prediction accuracy.

# Dataset:
The dataset used for this project is the Kaggle Bike Sharing Demand dataset, which contains historical data from the Washington D.C.-based Capital Bikeshare program. The data includes features such as:
Date and time information
Weather conditions
Holiday and working day indicators
Counts of hourly bike rentals categorized into casual and registered users

# Application:
This project demonstrates the practical application of machine learning in urban mobility. By predicting bike rental demand, the model can help optimize resource allocation for bike-sharing systems, improve customer satisfaction, and support urban planning initiatives. It also serves as a reference for using AutoGluon to handle tabular data effectively in real-world scenarios.

The implementation includes:
Data Analysis: A thorough exploration of the dataset to understand the features and relationships.
Model Training: Employing AutoGluon’s Tabular Prediction to train a baseline model on the dataset.
Feature Engineering: Incorporating engineered features to improve the model's performance.
Model Iteration: Iteratively refining the model by adjusting hyperparameters and utilizing the enhanced dataset.
Evaluation: Comparing performance metrics and submitting predictions to Kaggle for ranking.
